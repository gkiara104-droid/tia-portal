# Simulador PLC S7-1200 (KOP)

## Subir a GitHub Pages
1. Crea un repositorio nuevo en github.com y sube TODO el contenido de esta carpeta (index.html, sw.js, manifest.webmanifest, iconos y la carpeta img).
2. Settings -> Pages -> Source: "Deploy from a branch" -> rama main, carpeta / (root) -> Save.
3. En 1-2 minutos estara en https://TU-USUARIO.github.io/NOMBRE-REPO/

## Instalarlo como app
Abre esa direccion en Chrome o Edge (ordenador o movil) y pulsa "Instalar" en la barra de direcciones (o Menu -> Instalar app / Anadir a pantalla de inicio). Luego funciona sin internet.

## Uso sin GitHub
Tambien puedes abrir index.html directamente (doble clic). Funciona igual, pero sin instalacion como app.

## Memoria
Programa, tabla de variables, maqueta elegida y crono se guardan solos en el navegador. Boton "Copia" para descargarlos y "Restaurar" para recuperarlos en otro equipo.
